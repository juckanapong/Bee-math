## ระบบบัญชีและซิงก์ (ระยะ 2a · Supabase)
ไม่บังคับ: ถ้ายังไม่ตั้งค่า แอปทำงานแบบเก็บความคืบหน้าในเครื่องเหมือนเดิม เมื่อตั้งค่าแล้วผู้เรียนสมัคร/เข้าสู่ระบบได้ที่ **ตั้งค่า › บัญชี** (หรือ "มีบัญชีอยู่แล้ว?" ในหน้าเริ่มต้น)

**ขั้นตอนตั้งค่า (ครั้งเดียว ~10 นาที)**
1. สมัคร https://supabase.com › **New project** (เลือก Region: Singapore ใกล้ไทยที่สุด) ตั้งรหัสผ่านฐานข้อมูลแล้ว**เก็บไว้เอง ห้ามใส่ในโค้ด**
2. **SQL Editor › New query** › วางทั้งไฟล์ `supabase/schema.sql` › **Run** (สร้างตาราง `profiles` · `progress` พร้อม Row Level Security)
3. **Authentication › URL Configuration**: Site URL = `https://juckanapong.github.io/Bee-math/` และเพิ่มเดียวกันใน Redirect URLs (ใช้กับลิงก์ยืนยันอีเมลและลืมรหัสผ่าน)
4. **Project Settings › API**: คัดลอก Project URL และ publishable key (หรือ anon public key) ไปใส่ใน `js/config.js`
5. `git commit` + `git push` แล้วลองสมัครบัญชีบนเว็บจริง

**วิธีซิงก์**
- ล็อกอินอยู่: ทุกครั้งที่บันทึกจะส่งขึ้นคลาวด์ภายใน ~2.5 วินาที · ออฟไลน์จะรอส่งเมื่อกลับมาออนไลน์ · เปิดแอปจะดึงข้อมูลล่าสุดลงมา
- สมัครบัญชีใหม่: ความคืบหน้าที่เล่นไว้ในเครื่องจะถูกย้ายเข้าบัญชี
- เข้าสู่ระบบในเครื่องที่มีความคืบหน้าอยู่แล้ว: **รวมกัน** (ใช้ชุดที่ XP มากกว่าเป็นหลัก แล้วรวมด่าน ตรา หีบ เรื่องเล่าที่เคยได้จากอีกชุด) ถ้าข้อมูลในเครื่องเป็นของบัญชีอื่น จะไม่รวม
- ออกจากระบบ: ส่งข้อมูลล่าสุดขึ้นก่อน แล้ว**ล้างข้อมูลในเครื่อง** (ปลอดภัยสำหรับคอมที่ใช้ร่วมกันในโรงเรียน)
- ลบบัญชี: ลบข้อมูลทั้งหมดบนคลาวด์ถาวร (ฟังก์ชัน `delete_my_account`)

**ความปลอดภัย**
- `js/config.js` เปิดเผยได้ (repository เป็น Public): publishable/anon key ออกแบบให้ใช้ในเบราว์เซอร์ ทุกตารางเปิด RLS ให้ผู้ใช้อ่าน/เขียนได้เฉพาะข้อมูลของตัวเอง
- **ห้าม**ใส่ service_role key หรือรหัสผ่านฐานข้อมูลในโค้ดเด็ดขาด
- XP ส่วนตัว (เลเวล ตรา) ยังคำนวณในเบราว์เซอร์ ส่วน **XP ลีก** (ลีก เพื่อน ห้องเรียน) เซิร์ฟเวอร์ตรวจคำตอบและคิดเอง ดู "XP ลีกที่เซิร์ฟเวอร์ตรวจ (ระยะ 3)"
- ผู้ใช้ส่วนใหญ่เป็นนักเรียน: ก่อนใช้จริงควรมีนโยบายความเป็นส่วนตัว และขอความยินยอมจากผู้ปกครองตาม PDPA สำหรับผู้เยาว์

## ห้องเรียนและแดชบอร์ดครู (ระยะ 2d)
**ตั้งค่า (ครั้งเดียว)**
1. Supabase › SQL Editor › วางทั้งไฟล์ `supabase/classroom.sql` › Run (หลัง schema/league/friends)
2. Supabase › Authentication › Sign In / Providers › เปิด **Allow anonymous sign-ins** (ให้นักเรียนที่ไม่มีอีเมลเข้าห้องด้วยรหัสได้)

**ครู** (ต้องใช้บัญชีอีเมล) · เมนู **ห้องเรียน › เปิดแดชบอร์ดครู**
- สร้างห้อง ได้รหัสเข้าห้อง เช่น `HIVE-7KQ2` แจกให้นักเรียน
- ภาพรวม: จำนวนนักเรียน · เรียนวันนี้ · ความแม่นยำเฉลี่ย · จำนวนที่ต้องการความช่วยเหลือ
- มอบหมายงาน: เลือกบทและด่าน + วันส่ง · ดูความคืบหน้า (ครบ / กำลังทำ / ยังไม่เริ่ม)
- ความแม่นยำรายบทเรียนของทั้งห้อง (จาก 10 ข้อล่าสุดของแต่ละทักษะ) · ต่ำกว่า 65% แนะนำให้ทบทวน
- ตารางนักเรียน: กำลังเรียนด่านไหน · แม่นยำ · สตรีค · XP สัปดาห์ · งานค้าง · สถานะ (**ต้องช่วย** = ตอบ ≥ 10 ข้อและแม่นยำ < 60% · **ไม่เข้า n วัน** = ไม่ได้ซิงก์ ≥ 3 วัน) · นำนักเรียนออก · ลบห้อง
- แท็บ **ลีก**: นักเรียนอยู่ลีกไหนกี่คน (เทียบ 4 สัปดาห์ก่อน) · ผลสัปดาห์ที่แล้ว · ควรตามดู (ตกลีก / ไม่ได้แข่ง ≥ 2 สัปดาห์) · ตารางลีกรายสัปดาห์ 8 สัปดาห์ของทุกคน · แตะชื่อดูเส้นทางลีกรายคน · บนมือถือดูได้ที่หน้าอันดับ › **นักเรียนในห้อง** (แสดงเฉพาะบัญชีที่เป็นครู)
  - ตั้งค่า: SQL Editor › วาง `supabase/league_class.sql` › Run (หลัง `classroom.sql` และ `league_v3.sql` · รันซ้ำได้)

**นักเรียน**
- มีอีเมล: เข้าสู่ระบบ แล้ว **ตั้งค่า › ห้องเรียน** กรอกรหัสห้อง
- ไม่มีอีเมล: หน้าบัญชี › แท็บ **รหัสห้องเรียน** กรอกชื่อ + รหัสห้อง (Anonymous sign-in · ใช้ได้บนเครื่องนั้น ย้ายเครื่องด้วยไฟล์สำรอง · ถ้าออกจากระบบจะกลับเข้าบัญชีเดิมไม่ได้ แอปจะเตือนก่อน)
- งานจากครูแสดงเป็นแถบบนหน้าหลัก (เลยกำหนดเป็นสีแดง ใกล้ส่งเป็นสีส้ม) แตะเพื่อไปด่านถัดไปของงาน

**ความเป็นส่วนตัว:** ครูเห็นข้อมูลเฉพาะนักเรียนที่เข้าห้องของตัวเองด้วยรหัส · นักเรียนออกจากห้องได้เอง · บัญชีแบบไม่ใช้อีเมลสร้างห้องไม่ได้ · Supabase แนะนำให้เปิด CAPTCHA เมื่อเปิด anonymous sign-ins กับผู้ใช้จำนวนมาก

## XP ลีกที่เซิร์ฟเวอร์ตรวจ (ระยะ 3)
ทำแบบ Duolingo: แอปไม่บอกเซิร์ฟเวอร์ว่า "ได้กี่ XP" อีกแล้ว แต่ส่ง**คำตอบ**ไปให้ตรวจ เซิร์ฟเวอร์สร้างโจทย์ชุดเดิมขึ้นมาใหม่ ตรวจคำตอบ แล้วคิด XP ด้วยกติกาเดียวกับแอป

**ลำดับการทำงาน**
1. เริ่มรอบ (บทเรียน ด่านทดสอบ ฝึกฝน ระดับตำนาน ข้ามบท วัดระดับ ผึ้งเร่งรีบ เรื่องเล่า): แอปสุ่ม `id` และ `seed` แล้วเรียก `session_begin` (ไม่รอผล ผู้เรียนไม่ต้องรอ) เซิร์ฟเวอร์จดเวลาเริ่มเอง
2. ระหว่างทำ: โจทย์ข้อที่ n สร้างจาก `makeQuestion(ตัวสร้าง, ระดับ, subSeed(seed, n))` ใน `js/data.js` · แอปเก็บคำตอบดิบทุกข้อ
3. จบรอบ (หรือออกกลางทาง): ใส่คิว **outbox** ใน localStorage (แยกตามบัญชี) แล้วส่งไปที่ Edge Function `session-submit` · เน็ตหลุดจะลองใหม่เป็นระยะ (สูงสุด 3 วัน) · ส่งซ้ำได้โดยไม่นับซ้ำ
4. Edge Function ตรวจด้วย `supabase/functions/_shared/verify.mjs` แล้วเรียก `session_complete` ซึ่งบวก XP เข้าลีกและเก็บสถิติรายวันสำหรับภารกิจ
5. รับรางวัลภารกิจ: เซิร์ฟเวอร์ตรวจกับสถิติรายวันว่าทำครบจริงก่อนให้ XP ลีก · XP สองเท่า: เซิร์ฟเวอร์จดช่วงเวลาเอง (ไม่เกิน 3 ครั้งต่อวัน)

**สิ่งที่เซิร์ฟเวอร์ตรวจ**
| เรื่อง | กติกา |
|---|---|
| โจทย์ | ตัวสร้างต้องอยู่ในด่าน/บทนั้น และครบชุดตามรอบ · คำตอบต้องตรงกับโจทย์ที่สร้างจาก seed |
| ลำดับ | ข้อหลักตามลำดับ · ข้อทวน (เฉพาะบทเรียน/ฝึกฝน) ต้องเป็นข้อที่ผิดจริง ตามลำดับ และใช้โจทย์เดิม |
| เวลา | อย่างน้อย 1.2 วินาทีต่อข้อ (เรื่องเล่า 2 วินาทีต่อขั้น) นับจากเวลาเริ่มที่เซิร์ฟเวอร์จด · ผึ้งเร่งรีบตรวจนาฬิกา 60 วินาที +2/−5 ซ้ำทุกข้อ |
| XP | เหมือนแอป: บทเรียน 10 · ด่านทดสอบ 20 (≥ 70%) · ตำนาน 30 · ข้ามบท 20 · ฝึกฝน 5 + ครึ่งหนึ่งของข้อที่ถูก · ไม่ผิดเลย +5 · โจทย์ท้าทาย +1 (สูงสุด 5) · วัดระดับ 10 (ครั้งเดียวต่อบัญชี) · ผึ้งเร่งรีบ = ข้อที่ถูก · เรื่องเล่า 15 |
| ไม่ผ่าน | รอบนั้นได้ XP ลีก 0 และเก็บเหตุผลไว้ใน `xp_sessions.result` (แอปไม่ส่งซ้ำ) |

**ข้อจำกัดที่ยังเหลือ**
- เริ่มรอบตอนออฟไลน์ (หรือก่อนเข้าสู่ระบบ) ได้ XP เฉพาะในเครื่อง ไม่นับในลีก
- หัวใจและระดับความยากยังอยู่ในเครื่อง: เซิร์ฟเวอร์เชื่อระดับความยากที่แอปบอก (มีผลแค่โบนัสโจทย์ท้าทายสูงสุด 5 XP ต่อรอบ)
- โค้ดเปิดเผย คนที่เขียนโปรแกรมเป็นยังเขียนบอทตอบให้ได้ แต่ต้องตอบถูกจริง ใช้เวลาตามจริง และติดเพดาน 300 XP ต่อวัน

**ตั้งค่า (ครั้งเดียว · ทำตามลำดับ)**
1. Supabase › SQL Editor › วางทั้งไฟล์ `supabase/sessions.sql` › Run (หลัง schema/league/league_v2)
2. Deploy Edge Function (ต้องมี Node.js):
   ```sh
   npx supabase login
   npx supabase functions deploy session-submit --project-ref vgzyystxqwtchtianjzw
   ```
   หรือ Supabase › Edge Functions › Deploy a new function › ตั้งชื่อ `session-submit` แล้วสร้างไฟล์ให้ตรงกับ `supabase/functions/session-submit/index.ts` และ `supabase/functions/_shared/*.mjs`
3. `git push` แอปรุ่นใหม่ (service worker เวอร์ชันใหม่จะโหลดให้ผู้ใช้เอง)

ถ้าทำข้อ 3 ก่อนข้อ 2: ผลของรอบจะค้างในคิวรอจน deploy ฟังก์ชันเสร็จ (ไม่หาย ภายใน 3 วัน) · ดูข้อผิดพลาดได้ที่ Supabase › Edge Functions › session-submit › Logs

**แก้ `js/data.js` เมื่อไร ต้องทำตามลำดับนี้ทุกครั้ง** (ไม่งั้นเซิร์ฟเวอร์จะสร้างโจทย์ไม่ตรงกับแอป แล้วปฏิเสธรอบเรียน)
```sh
node tools/build-shared.mjs      # สร้าง content.mjs จาก js/data.js และเก็บรุ่นที่ commit ล่าสุดไว้เป็น content_prev.mjs
node tools/test-sessions.mjs     # ทดสอบตัวตรวจ
npx supabase functions deploy session-submit --project-ref vgzyystxqwtchtianjzw --use-api   # deploy ฟังก์ชันก่อน
git push                         # แล้วค่อยปล่อยแอป
```
เซิร์ฟเวอร์ตรวจกับเนื้อหารุ่นปัจจุบันก่อน ถ้าไม่ผ่านจะลองรุ่นก่อนหน้า (`content_prev.mjs`) ผู้ที่ยังเปิดแอปรุ่นเก่าค้างไว้ระหว่างอัปเดตจึงไม่เสีย XP ลีก (`xp_sessions.result.content = 'previous'`) · รันซ้ำระหว่างพัฒนาได้ รุ่นก่อนหน้ามาจาก commit ล่าสุดเสมอ
ห้ามใช้ `Math.random()` ตรง ๆ ใน `js/data.js` ใช้ `rand()` `R()` `pick()` `shuffle()` แทน (ไม่งั้นโจทย์จาก seed จะไม่ตรงกัน)

## แจ้งเตือน Push · เป้าหมายสตรีค · ฟีดเพื่อน (ระยะ 6)
**แจ้งเตือน Push** (เตือนแม้ปิดแอป)
| เรื่อง | รายละเอียด |
|---|---|
| เปิดใช้ | ตั้งค่า › เตือนให้มาเรียน + เข้าสู่ระบบ + อนุญาตการแจ้งเตือน · แต่ละเครื่องสมัครแยกกัน (สูงสุด 10 เครื่องต่อบัญชี) |
| เมื่อไร | ถึงเวลาที่เลือกและยังไม่ได้เรียนวันนี้ · วันละไม่เกิน 1 ครั้งต่อเครื่อง · ไม่ส่ง 21:00–07:00 (เวลาที่เลือกนอกช่วงจะเลื่อนเข้าช่วง) |
| ข้อความ | ให้กำลังใจ ไม่ใช้ชื่อ (แสดงบนหน้าจอล็อก) เช่น "สตรีค 12 วันของคุณรออยู่ มาเรียนสัก 1 บทนะ" |
| ปิด | ปิดสวิตช์ในตั้งค่า หรือออกจากระบบ → ลบการสมัครของเครื่องนั้นทันที |
| iPhone/iPad | ต้องเพิ่มแอปลงหน้าจอโฮมก่อน (iOS 16.4 ขึ้นไป) แอปบอกผู้ใช้ในหน้าตั้งค่า |
| ไม่มีบัญชี | ใช้การเตือนแบบเดิม (ทำงานเมื่อเปิดแอปค้างไว้) |

**เป้าหมายสตรีค** (หน้าสตรีค): เลือกเรียนต่อเนื่องเพิ่มอีก 7 / 14 / 30 / 50 วัน ได้น้ำหวาน 20 / 40 / 80 / 150 ทันทีที่ครบ (แสดงในหน้าจบบทเรียน) · สตรีคขาดก่อนครบ = ตั้งใหม่ · เก็บใน `S.streakGoal`

**ฟีดเพื่อน** (หน้าเพื่อน › ความเคลื่อนไหว): ผ่านด่านทดสอบ · ผ่านระดับตำนาน (Edge Function บันทึกจากรอบที่ตรวจแล้ว) · เลื่อนลีก (ทริกเกอร์ตอนตัดสินลีก) · สตรีคถึง 7/30/100/365 วัน · ครบเป้าหมายสตรีค (แอปแจ้ง) · เห็นเฉพาะตัวเองและเพื่อน 14 วันล่าสุด · กด "ให้กำลังใจ" ได้คนละครั้งต่อเหตุการณ์

**ตั้งค่า (ครั้งเดียว · ทำตามลำดับ)**
1. SQL Editor › วาง `supabase/notify_feed.sql` › Run
2. ความลับของฟังก์ชัน (กุญแจลับ VAPID ห้ามใส่ในโค้ด · กุญแจสาธารณะอยู่ใน `js/config.js` ต้องเป็นคู่เดียวกัน):
   ```sh
   npx supabase secrets set --project-ref vgzyystxqwtchtianjzw VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:... CRON_SECRET=...
   npx supabase functions deploy push-send --project-ref vgzyystxqwtchtianjzw --use-api --no-verify-jwt
   npx supabase functions deploy session-submit --project-ref vgzyystxqwtchtianjzw --use-api
   ```
3. ตั้งเวลาเรียก `push-send` ทุก 15 นาที (SQL Editor · ใส่ CRON_SECRET ค่าเดียวกับข้อ 2):
   ```sql
   create extension if not exists pg_cron;
   create extension if not exists pg_net;
   select vault.create_secret('<CRON_SECRET>', 'beemath_cron_secret');
   select cron.schedule('beemath-push', '*/15 * * * *', $$
     select net.http_post(
       url := 'https://vgzyystxqwtchtianjzw.supabase.co/functions/v1/push-send',
       headers := jsonb_build_object('Content-Type', 'application/json', 'x-cron-secret',
         (select decrypted_secret from vault.decrypted_secrets where name = 'beemath_cron_secret')),
       body := '{}'::jsonb)
   $$);
   ```
   ดูผล: `select * from cron.job_run_details order by start_time desc limit 5;` และ Edge Functions › push-send › Logs (ตอบ `{ due, sent, gone, failed }`)
4. `git push` แอปรุ่นใหม่

ถ้าต้องสร้างกุญแจ VAPID ใหม่: `npx web-push generate-vapid-keys` แล้วแก้ทั้ง `js/config.js` และ secret ของฟังก์ชัน (การสมัครเดิมจะใช้ไม่ได้ ผู้ใช้ต้องปิด/เปิดการเตือนใหม่)

## ระบบหลังบ้าน: feature flags · สวิตช์ฉุกเฉิน · ประกาศ · เก็บ error (ระยะ 7)
**ตั้งค่า:** SQL Editor › วาง `supabase/ops.sql` › Run · deploy `push-send` ใหม่ (ให้หยุดส่งเมื่อปิด flag)

แอปอ่านตาราง `app_config` ตอนเปิดและทุก 10 นาที แล้วจำไว้ในเครื่อง (`js/ops.js` โหลดเป็นไฟล์แรก ค่าที่จำไว้จึงมีผลทันทีที่เปิดแอป แม้ออฟไลน์)
| ต้องการ | SQL Editor |
|---|---|
| ปิดแจ้งเตือน Push ชั่วคราว | `update app_config set value = jsonb_set(value, '{push}', 'false') where key = 'flags';` |
| ซ่อนฟีดเพื่อน / รีแอ็กชันในลีก | เหมือนข้างบน เปลี่ยน `{push}` เป็น `{feed}` / `{reactions}` · เปิดคืนใช้ `'true'` |
| สวิตช์ฉุกเฉิน (เซิร์ฟเวอร์มีปัญหา/ค่าใช้จ่ายพุ่ง) | `update app_config set value = '{"offline": true, "message": "ข้อความถึงผู้ใช้"}' where key = 'kill';` |
| ปิดสวิตช์ฉุกเฉิน | `update app_config set value = '{"offline": false, "message": ""}' where key = 'kill';` |
| ประกาศบนหน้าหลัก | `update app_config set value = '{"text": "ปิดปรับปรุงคืนนี้ 22:00", "until": "2026-10-20T23:00:00+07:00"}' where key = 'notice';` (ลบประกาศ: `"text": ""`) |

**สวิตช์ฉุกเฉิน** (แบบ "zombie mode" ของ Duolingo): แอปหยุดซิงก์ ลีก เพื่อน ห้องเรียน ฟีด การส่งผลรอบเรียน และแจ้งเตือน Push (`push-send` ก็หยุดส่ง) แล้วแสดงแถบแจ้งผู้ใช้ นักเรียนยังเรียนต่อในเครื่องได้ · ปิดสวิตช์แล้วแอปซิงก์ของที่ค้างเอง (ภายใน 10 นาที หรือเมื่อเปิดแอปใหม่) · ข้อยกเว้น: รอบเรียนที่เริ่มระหว่างเปิดสวิตช์ได้ XP เฉพาะในเครื่อง ไม่นับในลีก (เหมือนเริ่มรอบตอนออฟไลน์) · การเข้าสู่ระบบที่ผู้ใช้กดเองยังทำได้

**เก็บ error:** error ของ JavaScript จากไฟล์ของแอป (ข้ามส่วนขยายเบราว์เซอร์และเน็ตหลุด) ส่งไป `report_error` ไม่เกิน 5 รายการต่อการเปิดแอป · รวมตามลายเซ็นและนับต่อวัน · ไม่ส่งตัวตน · เก็บ 30 วัน · ดูสรุป 7 วัน: `select * from client_errors_summary;` · เปลี่ยน `APP_VERSION` ใน `js/ops.js` ให้ตรงกับ `VERSION` ใน `sw.js` ทุกครั้งที่ปล่อยรุ่นใหม่ จะได้รู้ว่า error มาจากรุ่นไหน

**ไม่ได้ทำ A/B test:** ต้องเก็บข้อมูลพฤติกรรมผู้ใช้ ซึ่งขัดกับนโยบายความเป็นส่วนตัว ("ไม่มีตัวติดตามหรือระบบวิเคราะห์พฤติกรรม") และผู้ใช้ส่วนใหญ่เป็นผู้เยาว์

## ติดตั้งเป็นแอป (PWA) และใช้ออฟไลน์
เมื่อฝากเว็บแล้ว (ต้องเป็น https เช่น GitHub Pages) ผู้เรียนติดตั้ง BeeMath เป็นแอปได้ มีไอคอนบนหน้าจอ เปิดเต็มจอ และเรียนต่อได้แม้ไม่มีอินเทอร์เน็ต
- **Android / Chrome / Edge**: หน้าตั้งค่า › ปุ่ม "ติดตั้ง" (หรือเมนูเบราว์เซอร์ › ติดตั้งแอป)
- **iPhone / iPad (Safari)**: ปุ่มแชร์ › "เพิ่มไปยังหน้าจอโฮม"
- ไฟล์ที่เกี่ยวข้อง: `manifest.webmanifest` · `sw.js` (service worker) · `icons/`
- `sw.js` เปิดจากแคชทันทีแล้วโหลดเวอร์ชันใหม่เก็บไว้ (ผู้ใช้เห็นเวอร์ชันใหม่ในการเปิดครั้งถัดไป) **ถ้าเพิ่มหรือลบไฟล์ JS/CSS ให้แก้รายการ `APP_FILES` และเปลี่ยน `VERSION` ใน `sw.js`**
- เปิดจากไฟล์ (`file://`) จะไม่มีระบบ PWA ต้องเปิดผ่าน http/https เท่านั้น ทดสอบในเครื่องได้ด้วย `python3 -m http.server` แล้วเปิด http://localhost:8000

- **หน้าตั้งค่า** (เมนูข้าง หรือปุ่มฟันเฟืองในโปรไฟล์): เปิด/ปิดเสียง · ระดับเสียง · ลดการเคลื่อนไหว · ขนาดตัวอักษร 3 ระดับ · เป้าหมายรายวัน · เวลาเตือน · ชื่อ · สีกรอบอวตาร · **สำรอง/กู้คืนความคืบหน้าเป็นไฟล์** (ใช้ย้ายเครื่องได้ระหว่างที่ยังไม่มีระบบบัญชี) · รีเซ็ต

- โครงหน้าอยู่ที่ `shell()` / `sideNav()` / `rightRail()` ใน `js/app.js` และส่วน "รองรับทุกขนาดจอ" ท้าย `css/style.css`

## แอนิเมชัน
ทำเองด้วย CSS + SVG ทั้งหมด (ไม่ได้ใช้ไฟล์ของ Duolingo) อยู่ในส่วน "แอนิเมชัน" ของ `css/style.css`
- **น้องผึ้ง**: กะพริบตา · ปีกขยับ · ตอบถูกกระโดดเบา ๆ · ตอบผิดสั่นแล้วหงอย · จบบทกระโดดโบกมือ
- **ทำโจทย์**: ข้อใหม่เลื่อนเข้าจากขวา · ตัวเลือกที่ถูกเด้ง ที่ผิดสั่น · แถบความคืบหน้าไหลจากค่าเดิม และเปลี่ยนเป็นสีไฟเมื่อถูกติดกัน 3 ข้อขึ้นไป
- **หน้าผลลัพธ์**: ผึ้งเด้งเข้า · ช่องสรุปโผล่ทีละช่อง · ตัวเลข XP/ความแม่นยำนับขึ้นจาก 0 · รางวัลตามมาทีละชิ้น
- **เส้นทางบทเรียน**: ด่านที่เพิ่งผ่านพลิกเป็นสีทอง · ด่านถัดไปเด้งปลดล็อก
- **ชิปสถิติ** เด้งเมื่อสตรีค/น้ำหวาน/หัวใจเพิ่มขึ้น · ไฟสตรีคกระพือ · ปฏิทินสตรีคเติมสีทีละวัน · แถบเป้าหมายและภารกิจไหลเต็มตอนเปิดหน้า
- **เกมผึ้งเร่งรีบ**: การ์ดโจทย์เด้ง/สั่นตามคำตอบ · วงเวลาเป็นสีแดงและเต้นเมื่อเหลือน้อยกว่า 10 วินาที
- แอนิเมชันตอนเข้าหน้าเล่นครั้งเดียวต่อหน้า/ข้อ (`data-enter` บน `#app` ดู `sceneKey()` ใน `js/app.js`) ไม่เล่นซ้ำตอนกดเลือกคำตอบ
- ปิดอัตโนมัติเมื่อเครื่องตั้งค่า "ลดการเคลื่อนไหว" (prefers-reduced-motion)

## ฟีเจอร์
- **เส้นทางบทเรียน**: 6 บท บทละ 3 บทเรียน + ด่านทดสอบท้ายบท (ต้องได้ 70% ขึ้นไป) ต้องผ่านด่านก่อนหน้าจึงจะปลดล็อกด่านถัดไป
- **เรียนรู้**: การ์ดอธิบายเนื้อหาพร้อมแอนิเมชันแสดงขั้นตอนทีละบรรทัด
- **ประเภทโจทย์**: เลือกคำตอบ · พิมพ์คำตอบ · สร้างบาร์โมเดล · ตาชั่งสมดุล · **จับคู่** (สมการ↔คำตอบ, ข้อความ↔นิพจน์ ผิดได้ 1 ครั้ง) · **เรียงขั้นตอนการแก้** (มีขั้นหลอก 1 ขั้น) · **หาขั้นที่ผิด** · **ประกอบสมการจากชิ้นส่วน** · **ปักคำตอบบนเส้นจำนวน** · **กะตำแหน่งคำตอบเศษส่วน** · **เลือกได้หลายข้อ** · **ตารางค่า**
- **ระบบเกม**: XP, เลเวล, หัวใจ (ตอบผิดเสีย 1 ดวง ได้คืนทุก 30 นาที), สตรีครายวัน, คอมโบตอบถูกติดกัน
- **หีบสมบัติ** บนเส้นทาง (หลังบทเรียนที่ 2 ของทุกบท): เปิดได้ 1 ครั้ง ได้น้ำหวาน 15–30 และมีโอกาส 25% ได้ XP สองเท่า 15 นาที
- **ด่านทบทวนบท** (โผล่หลังผ่านด่านทดสอบ): ฝึกทักษะที่อ่อนลงในบทนั้น ขึ้นจุดแดง "ควรทบทวน" เมื่อมีทักษะความแข็งแรง ≤ 2 ขีด
- **ทดสอบข้ามบท**: ปุ่มใต้หัวบทที่ยังล็อก ตอบ 10 ข้อจากบทที่ยังไม่ผ่านจนถึงบทก่อนหน้า ผิดได้ไม่เกิน 2 ข้อ ผ่านแล้วบทก่อนหน้านับว่าผ่านทั้งหมด
- **เริ่มต้นใช้งาน**: เลือกเป้าหมายรายวัน (10/20/30/50 XP) เปิดการเตือน และเลือกเริ่มจากพื้นฐานหรือ **ทดสอบวัดระดับ** 10 ข้อ (ข้ามได้ถึงบทที่ 3)
- **ศูนย์ฝึกฝน** (ไม่เสียหัวใจ ทำจบได้หัวใจคืน 1 ดวง): ฝึกจุดอ่อนจากความแข็งแรงของทักษะ · ทบทวนข้อที่ผิดใน 7 วัน · ฝึกตามหัวข้อ
- **ระดับตำนาน**: ท้าทายบทที่ผ่านครบแล้ว 10 ข้อ ผิดได้ไม่เกิน 2 ข้อ ผ่านแล้วด่านทั้งบทเปลี่ยนเป็นมงกุฎ
- **ผึ้งเร่งรีบ**: เกมแก้สมการ 60 วินาที ตอบถูก +2 วินาที ผิด −5 วินาที
- **เรื่องเล่าโจทย์**: 3 เรื่อง บทสนทนาสลับคำถามให้ตั้งสมการเอง
- **สตรีค**: ปฏิทินรายเดือน ก้าวสำคัญ 7/30/100/365 วัน โล่สตรีค และซ่อมสตรีคภายใน 48 ชม.
- **น้ำหวาน & ร้านค้า**: เติมหัวใจ โล่สตรีค ซ่อมสตรีค XP สองเท่า 15 นาที และชุดแต่งน้องผึ้ง
- **ลีก 5 ระดับ**: ผึ้งน้อย → ผึ้งงาน → ผึ้งสำรวจ → ผึ้งองครักษ์ → นางพญา
- **ภารกิจประจำวัน** + **เหรียญประจำเดือน**, **ความสำเร็จ** (สถิติส่วนตัว + เหรียญ 5 ระดับ), **โปรไฟล์** + ตราสัญลักษณ์ 8 แบบ
- **น้องผึ้ง** ตัวละครช่วยสอน แสดงอารมณ์ตามคำตอบ
- ข้อที่ตอบผิดจะถูกนำกลับมาถามซ้ำท้ายบทเรียน (แบบ Duolingo)

**รูปแบบข้อมูลโจทย์** (ค่าที่ฟังก์ชันใน `G` คืนกลับ)
| `type` | ฟิลด์สำคัญ |
|---|---|
| `choice` | `choices` (HTML) · `answer` (ตำแหน่งคำตอบ) — ใช้ `choiceQ()` จะสลับตัวเลือกให้ |
| `input` | `answer` (จำนวนเต็ม) · `eq` (สมการ) — ใช้ `inputQ()` |
| `barbuild` | `a` (จำนวนกล่อง x) · `b` · `c` · `palette` |
| `match` | `pairs` [{ `a`, `b` }] 4 คู่ — ใช้ `matchQ()` |
| `order` | `start` · `steps` (ลำดับที่ถูก) · `palette` (ขั้นทั้งหมดรวมขั้นหลอก) |
| `build` | `tiles` (ชิ้นส่วน: ตัวเลข `x` `+` `-` `=`) · `nums` (ตัวเลขของโจทย์ที่ต้องใช้ครบ) · `answer` · `key` (ลำดับตัวอย่างที่ถูก) · ตรวจตามความหมาย: เรียงแบบไหนก็ได้ถ้าใช้ตัวเลขครบและได้คำตอบเดิม |
| `numline` | `min` `max` (ช่วง 10 หน่วย) · `answer` · `est: true` = แบบกะตำแหน่ง คลาดได้ `tol` |
| `multi` | `choices` · `answers` (ตำแหน่งที่ถูกทั้งหมด เรียงจากน้อยไปมาก) · ต้องเลือกครบและไม่เกิน |

โจทย์ `build` `numline` `multi` ตรวจด้วย `gradeAnswer()` ใน `js/data.js` ตัวเดียวกันทั้งแอปและเซิร์ฟเวอร์ · ตารางค่า (`tableRate`) เป็นโจทย์ `input` ที่มีตารางเป็นภาพประกอบ

## ปรับความยากอัตโนมัติ
แต่ละทักษะ (ตัวสร้างโจทย์ 1 แบบ) มีระดับความยาก 3 ระดับ เริ่มที่ "ปกติ" และปรับตามคำตอบของผู้เรียนเอง
| | กติกา |
|---|---|
| ขึ้นระดับ | ตอบถูกติดกัน **4 ข้อ** ในทักษะนั้น → ง่าย › ปกติ › ท้าทาย |
| ลงระดับ | ตอบผิดติดกัน **2 ข้อ** ในทักษะนั้น |

## ถามน้องผึ้ง (ผู้ช่วยอธิบาย · ไม่ใช้ AI)
หลังกดตรวจคำตอบ แถบเฉลยมีปุ่ม **ถามน้องผึ้ง** เปิดหน้าต่างแชตที่มีคำถามสำเร็จรูปให้แตะ (ไม่มีในแบบทดสอบวัดระดับ)
| คำถาม | น้องผึ้งตอบอย่างไร |
|---|---|
| ทำไมคำตอบของฉันผิด / ตรวจคำตอบให้หน่อย | แทนค่าคำตอบของผู้เรียนและคำตอบที่ถูกลงในสมการ เทียบสองข้างให้เห็น และบอกว่า x ควรมากขึ้นหรือน้อยลง |
| ทำไมต้องแก้ตามลำดับนี้ | อธิบายตามชนิดสมการ (บวก/ลบ · คูณ · สองขั้น "ใส่ถุงเท้าก่อนรองเท้า" · ตัวแปรสองข้าง · วงเล็บ · เศษส่วน) พร้อมขั้นตอนจากตัวเลขของข้อนั้น |
| อธิบายด้วยบาร์โมเดลหน่อย | วาดสมการแบบ ax + b = c เป็นแถบ แล้วแสดงการตัด/เติมส่วนที่เป็นค่าคงที่และแบ่งกล่อง |
| ขอโจทย์คล้าย ๆ กัน 1 ข้อ | สร้างโจทย์ใหม่จากตัวสร้างเดิมที่ระดับความยากของผู้เรียน ให้เลือกคำตอบ 3 ตัวเลือก แล้วเฉลย |
| ทบทวนเนื้อหาเรื่องนี้ | แสดงการ์ดสรุปของบทเรียนที่โจทย์ข้อนี้มาจาก |
| ขอดูวิธีทำอีกครั้ง | แสดงวิธีทำทีละขั้นของข้อนั้น |

คำอธิบายทั้งหมดคำนวณจากสมการของข้อนั้นเอง (`analyze()` ใน `js/askbee.js` แยกแต่ละข้างเป็น a·x + b) จึง **ฟรี ถูกต้องเสมอ ใช้ออฟไลน์ได้ และไม่มีข้อมูลออกจากเครื่อง** · โจทย์ที่ใช้ได้ต้องมีฟิลด์ `eq` (สร้างโดย `inputQ`/ตัวสร้างใน `js/data.js`) · ทดสอบกับโจทย์สุ่ม 8,100 ข้อ: แทนค่าแล้วสองข้างเท่ากันทุกข้อ

## เข้าสู่ระบบด้วย Google
ปุ่ม "เข้าสู่ระบบด้วย Google" / "สมัครด้วย Google" อยู่ในหน้าบัญชี (แท็บเข้าสู่ระบบและสมัครบัญชี) ใช้ `signInWithOAuth` ของ Supabase
- สมัครด้วย Google ต้องติ๊กยอมรับนโยบายก่อนเหมือนสมัครด้วยอีเมล · เข้าสู่ระบบด้วยบัญชีเดิมไม่ต้องติ๊ก (ถ้ายังไม่เคยยอมรับ แอปจะถามหลังเข้าสู่ระบบ)
- แอปไม่ใช้ชื่อจริงหรือรูปจาก Google: ชื่อในลีก/เพื่อน/ห้องเรียนคือ "ชื่อที่แสดง" ที่ผู้ใช้ตั้งเอง
- อีเมลเดียวกันที่เคยสมัครด้วยรหัสผ่าน (และยืนยันอีเมลแล้ว) Supabase จะรวมเป็นบัญชีเดียวกันให้อัตโนมัติ

**ตั้งค่าครั้งแรก**
1. [Google Cloud Console](https://console.cloud.google.com/) › สร้างโปรเจกต์ › **APIs & Services › OAuth consent screen**: User type = External · App name = BeeMath · ใส่อีเมลติดต่อ · Scopes ใช้ค่าเริ่มต้น (email, profile, openid) · **Publish app** (ถ้าค้างที่ Testing จะเข้าได้เฉพาะ test users)
2. **Credentials › Create credentials › OAuth client ID** › Web application
   - Authorized JavaScript origins: `https://juckanapong.github.io`
   - Authorized redirect URIs: `https://vgzyystxqwtchtianjzw.supabase.co/auth/v1/callback`
3. Supabase › **Authentication › Sign In / Providers › Google** › Enable › วาง Client ID และ Client Secret › Save
4. Supabase › **Authentication › URL Configuration**: Site URL = `https://juckanapong.github.io/Bee-math/` และมีที่อยู่เดียวกันใน Redirect URLs

- ไอคอนวาดเป็นเส้นแบบ SVG ทั้งหมด ไม่ใช้อีโมจิ
- น้องผึ้งมีหลายท่าทาง: ยิ้ม · เสียใจ · ดีใจชูมือ
- ตัวอักษรคมชัดอ่านง่าย (≥ 4.5:1) และพื้นที่กดอย่างน้อย 44px

## ข้อจำกัดของต้นแบบ
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น
- ผู้เล่นอื่นในลีกเป็นผู้เล่นจำลอง
- การเตือนให้มาเรียนแบบไม่มีบัญชีทำงานเฉพาะตอนเปิดแอปค้างไว้ (มีบัญชีแล้วใช้แจ้งเตือน Push ได้ ดูระยะ 6)
